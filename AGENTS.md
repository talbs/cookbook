# Agents

Notes for any coding agent working in this repo.

- Recipes follow [CONTRIBUTING.md](CONTRIBUTING.md), including its checklist.
- Run `npm test` before calling a recipe done. It has to pass.
- Never change an amount, a time or a temperature from a source without saying so.
- Never rename a file in `recipes/`. The file name is the recipe's address.
- Running the site and the project layout are in [README.md](README.md).
